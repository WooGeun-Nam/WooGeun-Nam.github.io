01 / 엑셀 데이터 연동

마스터 엑셀 데이터 파이프라인

GameData.xlsx 자동 동기화 (0.6초)

  • ItemMaster.csv (37행): 일반, 가구, 무기, 촉매 아이템 통합 정의
  • MonsterMaster.csv (4행): 슬라임, 고슴도치, 다람쥐, 보스 스탯
  • PropMaster / ElementChart / ItemEffects: 프랍, 원소 상성 매트릭스, 소모품 효과
  • Localization / Definitions / StageTheme: 다국어 매핑, 전역 상수, 테마

독립 실행 환경 폴백 및 사전 캐싱

전투, 탐험, 생활 성장 노드 27종은 시작 시 카테고리별 리스트로 사전 캐싱해 조회 비용을 없앴으며, 정식 빌드(.exe) 환경에서 외부 CSV 경로를 찾지 못할 때도 즉시 복구되는 내장 폴백 데이터를 탑재했습니다.

02 / 공격 분리와 성능 최적화

공격 모듈 분리와 메모리 최적화

공격 행동 모듈 4종 분리

  • ContactAttackModule: 근접 추적 및 접촉 판정
  • ChargeAttackModule: 전조 후 직선 돌진 및 벽 충돌 기절
  • RangedShooterModule: 적정 거리 유지 및 독 포자 투사체 발사
  • BossPhaseModule: 체력 구간별 보스 패턴 누적 실행

객체 풀링 및 버퍼 재사용 최적화

매 프레임 스탯 순회와 가비지 컬렉션 부하를 줄이기 위해 특성 스탯 O(1) 캐싱, 무기 타격과 몬스터 탐지용 고정 배열 버퍼 재사용, 그리고 탭 전환 시 반복 생성 및 삭제되던 UI 오브젝트의 풀링을 적용해 불필요한 메모리 할당을 억제했습니다.

03 / 동적 하우징과 네트워크

동적 거점 재구축과 네트워크 구조

동적 하우징 타일맵 및 외벽 재구축

방 규격이 6x6에서 8x8로 증축될 때 바닥과 벽 타일맵, 외벽 콜라이더 4개를 즉시 재구성하며, 좌하단(0,0) 기준 좌표계를 유지해 기존에 설치한 가구와 배치 스탯을 안전하게 보존합니다.

서버 판정 분리와 씬 전환 세션 정리

전투와 피격 판정은 P2P Listen Server 권한으로 처리하면서 역경직과 화면 진동은 로컬에서 즉시 실행합니다. 던전과 마을 씬 이동 전에는 기존 NetworkManager 종료 후 파괴 순서를 강제해 오브젝트 해시 충돌을 차단했습니다.

현재 구현 및 데모 확인 항목

  • 절차적 던전과 성소: 전장 구조 생성, 결계 봉쇄 및 수호자 처치 후 탈출 게이트 개방
  • 격자 가방과 창고: 탐험 가방, 보호 가방(드래그, 회전, 빠른 이동) 및 가구 자동 입고
  • 마이홈 하우징: B키 가구 설치와 해체, 배치 점수 반영 및 방 크기 동적 확장
  • 마을 UI와 시설: C키 스탯창, 모험 일지, 상점, 대장간, 건축, 게시판 모달 연결

차기 구현 예정 로드맵

  • 마을 NPC 3종 전용 UI: 대사 이후 전용 심사 및 감정 모달 연결 예정
  • 무기 장착과 모딩 UI: 인벤토리 내 무기 교체 및 개조 호출 경로 연결 예정
  • 보스 아레나 던전 편입: 뒤틀린 거목 보스전의 랜덤 던전 합류 예정
  • 인프라 확장: 미니맵, 사운드 믹서, 세이브 암호화 순차 적용 예정
