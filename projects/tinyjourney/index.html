01. 게임 개요 및 코어 루프

핵심 콘셉트

기억을 잃은 고양이 영웅이 6개의 테마 대륙을 돌파하며 잃어버린 힘의 파편을 되찾는 2D 탑다운 액션 RPG입니다. 인간의 시선이 닿지 않는 발밑 세계에서 버려진 도구(나뭇가지, 포크, 스푼)를 무기 삼아 괴물에 맞서는 묵직한 액션 감성을 지향합니다.

4단계 순환 코어 루프

Step 1

[전투·탐험]

스테이지 돌파 & 기믹 파훼

Step 2

[파밍]

부위별 장비·연금술 재료 수집

Step 3

[정비·성장]

상점 거래 & 물약 조합

Step 4

[도전]

보스 처치 & 상위 대륙 해금

익스트랙션 기반 텐션

방 단위 클리어 후 [다음 방으로 강행]과 [마을로 즉시 귀환]의 선택지를 제시하여, 획득한 전리품과 목숨을 건 하이 리스크-하이 리턴의 긴장감을 설계했습니다.

02. 전투 시스템 및 6대 무기군 아키타입 설계

기획 의도 : 무기 교체만으로 완전히 다른 조작감과 전술적 포지셔닝을 제공하기 위해 사거리, 공격 방식, 특수 기믹을 6개 아키타입으로 분리했습니다. 플레이어가 마주하는 몬스터 군집 형태나 보스 패턴에 맞춰 최적의 무기를 스왑하도록 유도합니다.

무기군사거리 / 판정공격 방식 및 특징특수 기믹 및 전술적 역할
한손검 (One-Handed Sword)근거리 부채꼴 베기빠른 공속과 짧은 후딜레이를 통한 히트 앤 런 표준 밸런스형안정적인 공수 전환, 가드 캔슬을 통한 빈틈 최소화
대검 (Greatsword)중거리 광역 횡베기공격 전/후 이동 속도 페널티, 묵직한 타격감과 광역 제압차징(Charging) 시 슈퍼아머(경직 면역) 및 2.5배 데미지·강한 넉백
단검 (Dagger)초근거리 연속 찌르기압도적인 공격 속도, 치명타 확률 +20% 기본 보정배후 공격(Backstab) 적중 시 1.5배 피해 및 순간 회피 연계
활 (Bow)원거리 관통 화살원거리 단일/직선 사격, 탄속 기반 정밀 조준 요구화살 수량(최대 10발, 2초당 1발 자동 장전) 자원 관리 및 풀차징 관통
지팡이 (Staff)원거리 유도 마법탄MP 소모 기반 타격, 폭발형 범위(AoE) 스플래시 데미지화상(지속 피해), 빙결(이동 둔화), 감전(체인 데미지) 등 원소 상태이상 부여
창 (Spear)중장거리 직선 찌르기좁고 긴 일직선 관통 판정을 활용한 거리 유지(Spacing) 특화창 끝점 타격(Sweet Spot) 시 1.3배 추가 피해 및 카운터 판정

03. 레벨 디자인 및 6개 스테이지 환경 기믹

기획 의도 : 2D 탑다운 시점의 평면적인 전투를 극복하기 위해 2.5D 절벽 고도(Elevation)와 대륙별 환경 기믹을 결합했습니다. 지형의 높낮이에 따른 물리 충돌과 시야 제어를 활용해 전략적 깊이를 확보했습니다.

2.5D 절벽 고도 및 공격 시인성 보정 규칙

  • 물리 충돌 및 Y-Sorting 계층 분리: 1층 지면과 2층 절벽 상단을 각각 별도의 타일맵 레이어로 분리하고, 절벽 측면 수직 암벽에 벽 콜라이더(Wall_Collider)를 배치하여 자연스러운 낙차감을 연출합니다.
  • 공격 시인성 보정: 캐릭터가 무기를 휘두르는 동안 시각적으로 대형 몬스터나 장애물에 가려지지 않도록 공격 판정 진행 중 Y-Sorting 가중치(+0.5f)를 동적으로 보정합니다.
  • 48×24 Expansive Arena: 단일 화면의 답답함을 배제하고 시네머신 가상 카메라 스크롤을 활용하여 광활한 전장 속 모퉁이 은폐 및 거리 유도 전술을 유도합니다.
스테이지테마 명칭핵심 환경 기믹 & 위험 요소등장 보스
Stage 1속삭이는 숲수풀 은신 기습, 밟으면 이동 속도가 저하되는 가시 덩굴 지대썩은 나무 정령 (Rotwood)

Stage 3버려진 고대 유적바닥 함정 발판(화살·창 트랩) 및 고대 수호 석상 회전 레이저유적 수호병기 (Ancient Guardian)
Stage 4얼어붙은 설원빙판 관성 미끄러짐 및 동상 게이지 누적(모닥불 거점 활용)서리 늑대 우두머리 (Frost Alpha)

02. Excel 마스터 데이터 실시간 동기화 파이프라인 (MasterDataPostprocessor)

기획자가 GameData.xlsx를 수정하고 저장하면, Unity 에디터가 이를 즉각 감지하여 MasterDataSO ScriptableObject 에셋으로 자동 파싱·직렬화하는 무코드(No-code) 밸런싱 파이프라인을 구축했습니다.

// MasterDataPostprocessor.cs 핵심 로직 요약
public class MasterDataPostprocessor : AssetPostprocessor
{
    private static void OnPostprocessAllAssets(string[] importedAssets, ...)
    {
        foreach (var assetPath in importedAssets)
        {
            if (assetPath.EndsWith("GameData.xlsx"))
            {
                // 1. ExcelDataReader로 몬스터·무기·아이템 시트 역직렬화
                var data = ExcelParser.ParseMasterData(assetPath);
                // 2. ScriptableObject에 데이터 주입 후 즉시 직렬화 저장
                MasterDataSO.Instance.Sync(data);
                EditorUtility.SetDirty(MasterDataSO.Instance);
                AssetDatabase.SaveAssets();
            }
        }
    }
}
  • 무코드 실시간 밸런싱: 코드 재컴파일이나 Unity 재실행 없이 엑셀 저장 즉시 인스펙터 및 게임 런타임에 몬스터 HP, 무기 공격력, 드랍률이 반영됩니다.
  • 런타임 오버헤드 0%: 런타임에 엑셀이나 JSON을 파싱하지 않고 사전 직렬화된 ScriptableObject 바이너리를 직접 참조하므로 모바일/PC 로딩 지연이 발생하지 않습니다.

03. 2.5D 절벽 타일셋 및 물리 콜라이더 자동 빌더 (ThemeAndPropAutoBuilder)

2D 탑다운 환경에서 입체적인 절벽 높낮이를 구현하려면 지면, 절벽 윗면, 수직 암벽의 타일 배치 및 충돌체 설정에 막대한 수작업이 소요됩니다. 이를 해결하기 위해 ThemeAndPropAutoBuilder 에디터 자동화 툴을 자체 개발했습니다.

에디터 자동화 파이프라인 핵심 기능

1.

타일시트 슬라이싱 및 3계층 분리: 5×8 규격의 테마별 타일 텍스처를 분석하여 1층 지면(Ground), 2층 절벽 상단(Cliff Top), 수직 암벽(Cliff Wall)으로 자동 분류 및 타일 에셋을 생성합니다.

2.

Custom Physics Shape 자동 생성: 보행 불가 영역인 수직 암벽과 낭떠러지 가장자리에 맞춤형 물리 충돌체를 자동 연산하여 부착합니다.

3.

복합 충돌체 최적화: CompositeCollider2D와의 연동을 통해 개별 타일의 콜라이더 버텍스를 병합하여 물리 연산 비용을 대폭 절감했습니다.

04. 코어 클라이언트 아키텍처 및 렌더링 최적화

ServiceLocator 기반 DI

전역 싱글톤의 강결합을 해소하기 위해 중앙 인터페이스 레지스트리를 구축했습니다. UIManager, AudioManager, PoolManager를 인터페이스로 주입받아 모듈 간 결합도를 최소화했습니다.

ObjectPoolManager (Zero-GC)

빈번하게 생성·소멸하는 투사체(화살, 마법탄), 데미지 플로팅 텍스트, 피격 파티클을 제네릭 큐 기반으로 재사용하여 런타임 가비지 컬렉션(GC Alloc) 스파이크를 원천 차단했습니다.

동적 Y-Sorting 렌더 순서 제어

모든 움직이는 오브젝트의 Y 좌표를 기반으로 실시간 정렬 순서를 갱신하며, 무기 휘두르기 시 공격 판정 시인성을 보장하기 위해 일시적 렌더 오더 가중치를 동적으로 부여합니다.
